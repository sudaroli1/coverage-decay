# Results — 2026-08-20

Snapshot corpus: SigmaHQ lineages from Long & Evans prepared bundle.
Analysis unit: a *revision step* (version_a → version_b) within one rule lineage.

**These figures supersede those in `2026-08-19.md`.** The suppression and relaxation
definitions were made symmetric; earlier counts (1,204 / 287 / 4.2:1) used an
asymmetric relaxation test and should not be cited.

---

## 1. Definitions used

A revision step is classified from the change in the number of predicates carrying
`CTX:POS` (positive selection) and `CTX:NEG` (exclusion) in the PGIR signature.

```python
def deltas(s):
    return (s['sig_b'].count('CTX:POS') - s['sig_a'].count('CTX:POS'),
            s['sig_b'].count('CTX:NEG') - s['sig_a'].count('CTX:NEG'))

# suppression : exclusions grew, positive selection did not
def is_suppression(s):
    pos, neg = deltas(s); return neg > 0 and pos <= 0

# relaxation  : exclusions shrank, positive selection did not shrink
def is_relaxation(s):
    pos, neg = deltas(s); return neg < 0 and pos >= 0

# excluded    : exclusions grew *alongside* new coverage — not a narrowing
def is_expansion_with_guard(s):
    pos, neg = deltas(s); return neg > 0 and pos > 0
```

The `pos <= 0` condition was added after inspecting `win_susp_add_sid_history.yml`,
where a rule gained `selection2` + `selection3` under
`condition: selection1 or (selection2 and not selection3)`. Its negation count rose
while coverage grew. 106 such revisions are excluded.

## 4. Persistence (survival analysis)

Clock starts at the commit that adds the exclusion. Event = a later revision in the
same lineage whose exclusion count returns to or below the pre-suppression level.
Steps of duration < 1 day dropped (same-PR sequencing artefacts).

```
suppressions with a measurable duration : 1063
  removed                               :  167
  still in place (censored)             :  896  (84.3%)
```

### 4.1 Kaplan–Meier, all suppressions (n = 1,063)

| Horizon | Fraction still in place |
|---:|---:|
| 30 days | 0.957 |
| 90 days | 0.943 |
| 180 days | 0.924 |
| 365 days | 0.877 |
| 730 days | 0.840 |
| 1095 days | **0.836** |

- **KM median survival: undefined** — the survival function never reaches 0.50,
  because the majority of exclusions are never removed.
- **RMST over 3 years: 954 of 1,095 days** (87% of the window).
- **Median follow-up (reverse KM): 1,291 days** — longer than the reporting
  horizon, so the flat tail is not an artefact of short observation.

> **Do not report a "median persistence."** The `days` column mixes 896 censored
> durations with 167 event times; its median is median *follow-up*, not median
> survival. The figures 1,380 / 162.5 / 1,175 that appear in earlier drafts are
> this error and must be removed.

### 4.2 Removal is a closing window

| | share of the 167 removals |
|---|---|
| within 180 days | 48% |
| within 365 days | 75% |

The hazard is concentrated early and approaches zero after roughly two years. An
exclusion that survives its first year is, in this corpus, not revisited.

### 4.3 Null result — persistence does not depend on coverage redundancy

Split on the number of rules covering the scarcest technique the lineage claims.

| group | n | censored | |
|---|---:|---:|---|
| sole coverage (min_coverage = 1) | 42 | 35 | |
| redundant coverage (min_coverage > 1) | 857 | 716 | |
| untagged | 164 | 145 | excluded from the test |

**Log-rank: p = 0.9603, test statistic = 0.00.** The two survival curves are
indistinguishable.

Reported as a finding, not a failure: nothing in the observed revision process is
weighted by consequence. Exclusions on a technique watched by a single rule receive
the same (absent) review as exclusions on a technique watched by many. The untagged
group behaves the same way.

The 42 singleton events remain relevant as a **severity** argument — those
exclusions have no fallback detection — but not as a persistence argument.

## 5. What is excluded (answering Dacier)

Dacier's objection: a narrowing is not necessarily a loss of coverage, if the
excluded attribute is one an adversary cannot assume. Classification of the 665
field-additions across the 1,098 suppressions:

| class | count | share |
|---|---:|---:|
| 1 — process / file identity | 538 | 80.9% |
| 2 — network identity | 40 | 6.0% |
| 3 — account identity | 22 | 3.3% |
| 4 — system-assigned | 40 | 6.0% |
| 5 — unclassified | 25 | 3.8% |

**90.2% of exclusions are written on attributes an adversary can influence**
(classes 1–3). The costless case Dacier described — an exclusion on a value the
adversary cannot forge — is class 4, at 6.0%.

---

## 7. Comparison with prior work — clocks differ

Prior work reports a median of **4.8 days**. That is time between *edits to a rule*.
The figures here are time to *reversal of a specific exclusion*. Different event,
different clock. Any side-by-side presentation must state this, or the contrast
reads as a three-order-of-magnitude error.
